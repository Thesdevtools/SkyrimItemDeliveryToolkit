# Skyrim Item Delivery Toolkit (SIDT)

実行中のSkyrimへ、選択したアイテムをロード済みNPCまたはプレイヤーへ配送するUtilityです。ゲームの再起動やNPCベースレコードの編集は行いません。

もともとは、インベントリ調整のためにVR環境を離れる負担を減らす目的でSkyrim VR向けに開発しました。その後、同じ仕組みをSkyrim AE 1.6.1170でも実装・検証できたため、両方を対象としています。

## ダウンロード

- [SIDT 0.9.8 Release](https://github.com/Thesdevtools/SkyrimItemDeliveryToolkit/releases/tag/v0.9.8)
- 通常利用では、Release Assetsの `Skyrim-Item-Delivery-Toolkit-0.9.8.zip` をダウンロードしてください。
- ソースコードは、同じReleaseに添付した `Skyrim-Item-Delivery-Toolkit-0.9.8-src.zip` です。

## インストール後のセキュリティ確認

インストールまたは実行の前に、ダウンロードしたアーカイブを普段から信頼している
セキュリティツールで確認してください。Release の SHA-256 は、ダウンロードした
ファイルが公開した成果物と一致するかを確認するためのものです。ハッシュの一致だけで
安全性が保証されるわけではありません。

- **Windows 10/11:** アーカイブを右クリックし、必要であれば **その他のオプションを確認** を選んでから、**Microsoft Defender でスキャン** を実行します。
- **VirusTotal:** アーカイブを [VirusTotal](https://www.virustotal.com/gui/home/upload) にアップロードし、結果を利用者自身で確認することもできます。

第三者のスキャン結果に依存せず、利用するかどうかは利用者自身で判断してください。

## 仕組み

SIDTは2つのコンポーネントで構成されます。

- **Delivery Post**：MO2構成を読み取り、Windows上で配送指示を作成するデスクトップアプリです。
- **Delivery Courier**：ゲーム内で配送指示を受け取り、最低所持数に不足している分だけを追加するSKSEプラグインです。

NPCのベースレコードは変更しません。アイテムの削除、装備変更、AI再評価も行いません。

本MODは一般的なQOLやバランス調整MODではなく、特定用途向けのツールです。通常プレイではチート相当の使い方もできますが、Skyrimを再起動せずに装備を渡せるため、MOD開発、構成確認、撮影、装備テストにも利用できます。既存のアイテム配布MOD、コンソールツール、インベントリ管理MODを置き換えることは意図していません。

## 対応環境

- Skyrim VR 1.4.15 + SKSEVR 2.0.12以降
- Skyrim AE 1.6.1170 + SKSE64 2.2.6以降

Skyrim SE 1.5.97には対応していません。

## 必要なもの

- Mod Organizer 2
- 選択したSkyrim環境に対応するSKSE
- .NET 8 Desktop Runtime (x64)

## インストールと基本操作

1. メインアーカイブをMO2でインストールします。
2. FOMODでSkyrim VRまたはSkyrim AE 1.6.1170の一方を選びます。
3. インストールしたMODフォルダー内の `SkyrimItemDeliveryPost.exe` を起動します。
4. 初回起動時に、MO2のmodsフォルダー、プロファイル、配送出力先を確認します。
5. Skyrimを起動し、配送先とアイテムを選んで「配送を実行」を選びます。

最低所持数は、受取人の所持数が指定値に満たない場合だけ不足分を補う設定です。

- **AE**：インゲーム中は即時配送されます。メニュー表示中はゲームへ戻ってください。
- **VR**：接続環境によって異なります。届かない場合はゲーム内メニューを一度開閉してください。

確認済みの例：

- Pico + SteamVR：即時配送
- Pico + Virtual Desktop / VDXR：メニュー操作後に配送

VR環境はヘッドセット、PC接続ソフトウェア、OpenXRランタイムの組み合わせが多いため、ほかの環境での動作報告を歓迎します。

## 現在の制限

- Delivery Postで通常選択できるのは武器・防具と、内蔵された一部のVanilla必須品です。
- **食べ物は現在選択できません。今後のアップデートで対応予定です。**
- 配送処理時にロードされていないNPCは、自動的には再試行されません。
- すべてのSKSEフック系MODとの共存を保証するものではありません。

## トラブルシューティング

- Delivery PostとMO2が同じプロファイルを参照していることを確認してください。
- 出力先がMO2の物理的な `overwrite` フォルダー、または明示的に選択した出力MODであることを確認してください。
- SKSEログフォルダーの `SkyrimItemDeliveryCourier.log` を確認してください。
- VRで配送待ちが続く場合は、ゲーム内メニューを一度開閉してください。
- AEではメニューを閉じてゲームへ戻ってください。

Delivery Postを完全に初期化する場合は、アプリを終了して `%LOCALAPPDATA%\SkyrimItemDeliveryPost` を削除してください。MO2のoverwriteフォルダー全体は削除しないでください。

## 開発とAIの利用について

SIDTは作者が方針と責任を持って進めているUtilityプロジェクトです。要件、設計、安全上の原則、ユーザー体験、リリース判断は作者が決定し、Skyrim VRおよびAEの実環境で動作検証を行っています。

MOD開発の勉強も兼ねて、実装、リファクタリング、コードレビュー、技術調査、ドキュメント、翻訳、配布パッケージ作成、テスト計画などにAIコーディングツールを広く利用しています。採用内容は作者が確認し、最終的な設計判断を行ったうえで、ビルドと実機テストを実施しています。

一部の紹介イラストと日英ドキュメントは、生成AIで作成または下書きし、作者が選定・編集しています。AI生成イラストはコンセプト画像であり、ゲーム内のスクリーンショットではありません。AI生成の音声、台詞、ゲーム内テクスチャ、メッシュ、キャラクター素材は含まれていません。
